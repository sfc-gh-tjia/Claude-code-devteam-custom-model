## Commands
- `make doctor`: preflight (dependencies, ports, credentials). Run it before any build work.
- `make verify`: every gate on the current tree. "Done" means this is green in the current turn.
- `python3 harness/referee.py status --phase NN`: task states as small JSON. Read this, not logs.
- `make tokens`: token and cost telemetry for this repo.
- `make gateway` / `make probe`: inference runs through a local gateway (DeepSeek + NVIDIA free, `gateway/`). If calls fail, it is down.

## Layout
- `src/`, `tests/`: product code. <adjust>
- `work/`: the plan.
  - `spec.md`, `phases/NN.md`, `tasks/NNNN-*.md` (TOML front matter), `adr/`.
  - `ledger.md` and `evidence/` are generated by the referee.
- Control plane, changed only by humans: `harness/` (referee, guard, `project.toml`), `gateway/` (model routing) and `.claude/`.
- Runtime, gitignored: `.worktrees/task-NNNN/` (one per task) and `.loop/` (state, runs, jobs, logs).

## How work flows
1. spec → tasks.
2. For each phase, the `build-phase` workflow runs, task by task:
   1. QA writes failing tests.
   2. The referee freezes them.
   3. The implementer works in a worktree.
   4. The referee checks.
   5. The reviewers review.
   6. The referee integrates: it merges in a scratch tree, re-runs every gate, fast-forwards main, smoke-tests it, and reverts if main goes red.
3. A phase gate and a phase review close the phase.

## Rules for every agent
1. **The oracle is fixed.** Frozen tests are the oracle; never edit them. If one looks wrong, say so in `unsure_about`.
2. **Stay in scope.** Edit only your task's `files` (implementer) or `tests` (QA). Never run git write commands; the referee commits and merges.
3. **Pass by reference.** Read inputs from the paths in your prompt and write results to the path you are given. Never paste logs or file bodies into a reply.
4. **Read narrowly.** Use grep, `sed -n 'a,bp'` and `tail -50`. Never cat a file over ~300 lines or a whole log.
5. **Evidence, not opinion.** A claim that something passes quotes the command and its last lines.
6. **Control plane.** `.claude/`, `harness/` and `gateway/` are off-limits; the guard hook enforces this.
